# OTR MANAGER 카카오 채널 출석 스킬 서버

## 중요
- **카카오 챗봇 관리자센터의 채널 챗봇용** 서버입니다. 기존 카카오톡 **오픈채팅방에는 연결되지 않습니다**.
- 카카오톡 채널 연결, 스킬 등록 및 블록 연결이 별도로 필요합니다.
- 데이터는 기본적으로 서버 로컬 `attendance.json`에 저장됩니다. Render 같은 임시 파일 시스템에 배포하면 재시작/재배포 시 데이터가 사라질 수 있으므로 운영 시 **영구 디스크 또는 DB**를 구성하세요.
- 단일 Node 프로세스 기준 예제입니다. 여러 인스턴스 운영이나 동시 쓰기에는 DB가 필요합니다.
- 사용자 이름은 카카오 요청의 `properties.nickname`이 있으면 사용하며, 없으면 회원으로 표시될 수 있습니다. 사용자 식별은 `user.id`를 사용합니다.
- 방 규칙은 환경변수 `OTR_RULES`로 변경할 수 있습니다.
- 공개 엔드포인트는 요청 인증을 구현하지 않은 학습용 예제입니다. 실운영 시 접근 제한, 인증, 로그 최소화, 개인정보 고지/보관 정책을 추가하세요.

## 로컬 실행
1. Node.js 18 이상 설치
2. 이 폴더에서 `npm start` 실행
3. `http://localhost:3000/health` 에서 `ok` 확인
4. 외부 HTTPS 주소에 배포한 뒤 카카오 챗봇 관리자센터 → 스킬 → 스킬 생성에서 `https://<도메인>/skill` 등록
5. 시나리오에서 `출석`, `내출석`, `출석순위`, `출석부`, `벙만들기`, `규칙` 블록 생성. 각 블록에 해당 발화 등록 후 동일 스킬 연결. 요청 발화가 명령어로 전달되는지 봇테스트에서 확인.
6. 운영 채널 연결/배포 후 카카오톡 채널에서 테스트

## 지원 명령어
`출석`, `내출석`, `출석순위`, `출석부`, `벙만들기`, `규칙` (앞의 `/` 유무 무관)

## 테스트
`node test.js` 를 실행하면 로컬 HTTP 없이 출석 기능을 직접 확인할 수 있습니다. 실제 카카오 플랫폼 연동은 별도 테스트가 필요합니다.
